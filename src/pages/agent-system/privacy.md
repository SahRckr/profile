# agent-system privacy policy

_Last updated: 11 November 2026_

This policy covers agent-system, a personal automation program described on the [agent-system home page](/agent-system/).

## Who runs it

agent-system is run by Sahil Satishkumar for his own use. Contact: [sahilsatishkumar@gmail.com](mailto:sahilsatishkumar@gmail.com).

## Data accessed

agent-system accesses Sahil's own Google account only, with these permissions:

- **Gmail (read and modify)**, to read, label, archive and mark messages read.
- **Calendar events**, to create and move events on Sahil's own calendars.
- **Calendar list (read-only)**, to find which of Sahil's calendars to use.

It doesn't access any other person's Google account or data.

## How the data is used

Google data is used only to run Sahil's own automations, as described on the [home page](/agent-system/): sorting his inbox and planning his calendar. It isn't used for advertising, isn't sold, isn't used to profile anyone, isn't used for credit or lending decisions, and isn't used to build databases for anyone else.

## Sharing

The text of some emails and calendar entries is sent to Anthropic's Claude API to classify and summarise them for Sahil. Anthropic processes it under its commercial terms. Results are written to Sahil's own Obsidian notes. Google data isn't shared with anyone else.

## Storage and protection

Data is processed and stored on Sahil's own computer, in a local database and in his notes. The Google sign-in token is kept in the computer's credential store, not in the program's code.

## Retention and deletion

Data is kept for as long as Sahil uses agent-system. Deleting the local database and notes removes the stored data. Access can be revoked at any time from the Google Account page under **Security → Third-party apps & services** ([myaccount.google.com](https://myaccount.google.com/)).

## Limited Use

agent-system's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## AI and machine learning

Data from Google Workspace APIs isn't used to develop, improve or train generalised (non-personalised) AI or ML models.

## Changes to this policy

If the way agent-system uses Google data changes, this page will be updated and the date at the top will change.
